## 🌟 What is OmniDev?

**OmniDev** is an ultra-fast, client-side, zero-latency dashboard engineered for **AI engineers, software architects, and full-stack developers**. 

It eliminates tab clutter by unifying your most essential daily workflows into a sleek, cyberpunk-inspired glassmorphic interface:
- **Prompt Engineering Studio** with variable template injection.
- **Model Context Protocol (MCP)** visual server selector & configuration builder.
- **2026 AI Models Benchmark Radar** comparing prices, speeds, and coding benchmarks.
- **Offline DevToys Suite** (JWT Inspector, JSON Studio, Regex Tester, Hash/UUID Studio, Cron Explainer, Git Wizard).
- **Latency Numbers Every Programmer Should Know** with interactive comparative scaling.
- **Curated Awesome AI & Agent Directory**.

---

## 🚀 Key Features

### ⚡ 1. Interactive Prompt Engineering Studio
- **Dynamic Variable Injection**: Fill in `{{system_name}}`, `{{scale}}`, `{{code_snippet}}`, and watch your prompt dynamically compile in real time.
- **Battle-Tested Scenarios**: Senior Architect System Design, OWASP Security Audits, SOLID Refactoring, SQL Optimization, Incident Post-Mortems, OpenAPI 3.1 Specs.
- **1-Click Copy & Export**: Download completed prompts directly as formatted `.md` files.

### 🔌 2. Model Context Protocol (MCP) Configurator
- **Official & Community Catalog**: Filesystem, PostgreSQL, GitHub, Brave Search, Puppeteer, Memory Graph, Docker, Slack.
- **Instant `claude_desktop_config.json` Generation**: Toggle the servers you need and copy or download the generated configuration with zero syntax errors.
- **OS Path Hints**: Quick guide on config locations across Windows (`%APPDATA%`), macOS (`~/Library`), and Linux (`~/.config`).

### 🎯 3. 2026 AI Models & Latency Radar
- **Direct Model Comparison**: Claude 3.5 Sonnet, DeepSeek R1, DeepSeek V3, GPT-4o, Gemini 2.0 Flash, Llama 3.3 70B, Qwen 2.5 Coder.
- **Context, Pricing & Benchmark Metrics**: Compare tokens per second, input/output prices per 1M tokens, and HumanEval/SWE-bench scores.
- **Interactive Latency Scale**: Visual comparison of CPU L1 cache vs RAM vs SSD vs Cross-datacenter internet hops.

### 🛠️ 4. Developer Power Utilities (DevToys Suite)
- 🔑 **JWT Inspector**: Decode headers & payload claims with live countdown expiration checker.
- ✨ **JSON Studio**: Beautify (2 or 4 spaces), validate with line error reporting, and minify.
- 🔍 **Regex Playground**: Real-time evaluation against test strings with pre-configured recipes (Email, URL, IPv4, SemVer).
- 🔐 **Cryptographic Hashes & UUID Studio**: Instant client-side SHA-256, SHA-512, Base64, URL encoding, and batch UUID v4 generation.
- ⏰ **Cron Humanizer**: Natural English translation of 5-part cron expressions.
- 🐙 **Git Disaster Recovery Wizard**: Interactive remedies for "Undo last commit", "Squash commits", "Recover deleted branch".

### 📚 5. Cheatsheets & Awesome AI Directory
- **HTTP Status Codes Guide**: Color-coded response breakdown with actionable debugging tips.
- **Curated AI Ecosystem**: Quick reference to top autonomous coding agents (Cursor, Cline, Windsurf, Aider, v0, Bolt).

## 💻 Technical Highlights

- **Zero-Build Friction**: Pure Vanilla ES6+ modules and Tailwind CSS. No Webpack, Vite, or Node daemon required to run.
- **100% Client-Side & Private**: Your tokens, JWTs, prompts, and code never leave your browser.
- **Synthesized Audio Engine**: Subtle auditory feedback powered by the native Web Audio API (toggleable on/off).
- **Command Palette (`Ctrl + K`)**: Keyboard-driven navigation to search across tools, models, and prompts instantly.
- **Dark / Light Mode**: Seamless theme switching with localStorage memory.

## ⚡ Quickstart

### Run with 1 click locally

```bash
# 1. Clone the repository
git clone https://github.com/ilynx69/awesome-ai-devtools.git

# 2. Navigate to the project directory
cd awesome-ai-devtools

# 3. Start a lightweight static server (Python or Node)
python -m http.server 3000

# Or with npx:
npx serve .
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
