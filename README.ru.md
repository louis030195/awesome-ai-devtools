## О проекте

**OmniDev** — это рабочий стол и полиглотный инструментарий для **AI-инженеров, архитекторов и разработчиков**, функционирующий на 100% на стороне клиента с нулевой задержкой.

Интерфейс спроектирован в минималистичном инженерном стиле (в духе Linear и Vercel Geist), объединяя ключевые рабочие сценарии:

- **AI Копилот и лаборатория кода**: Интерактивный помощник разработчика для аудита безопасности, рефакторинга и генерации тестов на базе бесплатных облачных моделей и локального эвристического анализатора.
- **Студия промпт-инжиниринга**: Шаблоны промптов с динамической компиляцией параметров (`{{system_name}}`, `{{code}}`) и тестированием в AI.
- **Конфигуратор Model Context Protocol (MCP)**: Каталог серверов и генерация валидного файла `claude_desktop_config.json` для Claude Desktop и Cursor.
- **Калькулятор емкости System Design**: Расчет QPS, годового прироста объема диска, сетевого трафика и размера оперативной памяти под кэш по правилу Парето (80/20).
- **Конвертер cURL в код**: Преобразование cURL-запросов в код на JavaScript `fetch()`, Python `requests`, Go `http`, Rust `reqwest` или Node.js `axios`.
- **Токенайзер и калькулятор стоимости**: Подсчет токенов BPE и сопоставление стоимости запросов в моделях Claude 3.5 Sonnet, GPT-4o, DeepSeek V3 и Gemini 2.0 Flash.
- **Набор утилит разработчика (DevToys)**: Декодер JWT с таймером времени жизни, форматирование и валидация JSON, песочница Regex, вычисление хэшей, генерация UUID v4, расшифровка Cron и рецепты для Git.
- **Мультиязычность**: Поддержка английского, русского и китайского языков с переключением в один клик.

## Функционал

### 1. AI Копилот и лаборатория кода
* **Бесплатный облачный доступ**: Прямое подключение к бесплатным инференс-моделям без обязательной регистрации.
* **Локальный эвристический анализатор**: Полная работа офлайн со 100% приватностью кода без отправки данных по сети.
* **Поддержка локальной Ollama и кастомных API**: Подключение к `http://localhost:11434` или использование собственных ключей Groq / OpenRouter.
* **Быстрые действия**: Аудит уязвимостей OWASP, чистый рефакторинг SOLID, создание Unit-тестов, трансляция в Rust/Python, расчет сложности Big-O.

### 2. Студия промптов
* **Динамические переменные**: Удобные поля для ввода параметров сценария с компиляцией в реальном времени.
* **Тестирование в AI**: Мгновенная передача составленного промпта в AI Копилот в один клик.
* **Экспорт**: Скачивание готовых промптов в формате `.md`.

### 3. Конфигуратор MCP
* **Каталог серверов**: Filesystem, PostgreSQL, GitHub, Brave Search, Puppeteer, Memory Graph, Docker, Slack.
* **Генерация конфигурации**: Формирование стандартного `claude_desktop_config.json`.
* **Справочник путей**: Подсказки расположения конфигурации для Windows (`%APPDATA%`), macOS (`~/Library`) и Linux (`~/.config`).

### 4. Утилиты разработчика (DevToys)
* **cURL в код**: Мгновенная конвертация сетевых вызовов в 5 популярных языков программирования.
* **Токенайзер**: Расчет токенов и прогнозирование затрат на API.
* **JWT Декодер**: Разбор заголовка и полезной нагрузки с мониторингом истечения токена.
* **JSON Студия**: Форматирование с выбором отступов, валидация с указанием ошибок и минификация.
* **Песочница Regex**: Тестирование регулярных выражений с набором готовых паттернов.
* **Хэши и UUID**: Вычисление SHA-256, SHA-512, Base64, URL-encode и генератор UUID v4.
* **Рецепты Git**: Готовые команды для решения частых проблем с ветками и коммитами.

### 5. Калькулятор System Design
* Ввод DAU, соотношения чтения к записи и размера записи.
* Расчет среднего и пикового QPS, прироста диска в год, требований к каналу связи и размера оперативной памяти под кэш.

## Полиглотная архитектура

Проект разработан с использованием нескольких языков:

| Язык | Путь | Назначение |
| :--- | :--- | :--- |
| **JavaScript (ES6+)** | `js/`, `index.html` | Клиентское веб-приложение, работающее на GitHub Pages без сборщиков. |
| **Python** | `python/omnidev.py` | Консольный CLI-инструмент для AI-инженеров: компиляция промптов, расчет архитектуры и запросы к AI. |
| **Rust** | `rust/src/main.rs` | Высокопроизводительный системный CLI для математических расчетов и экспорта MCP. |
| **TypeScript** | `types/index.d.ts` | Строгая типизация и интерфейсы данных проекта. |
| **Bash / Shell** | `scripts/setup.sh` | Скрипты быстрой настройки под Linux / macOS / Git Bash. |

## Быстрый старт

### Локальный запуск веб-версии
```bash
# Клонируйте репозиторий
git clone https://github.com/ilynx69/awesome-ai-devtools.git
cd awesome-ai-devtools

# Запустите легкий сервер (Python 3)
python -m http.server 3000

# Или через Node.js
npx serve .
```
Откройте [http://localhost:3000](http://localhost:3000) в браузере.

### Использование консольного CLI на Python
```bash
python python/omnidev.py list-prompts
python python/omnidev.py calc-capacity --dau 10000000 --writes 5
python python/omnidev.py ask-ai "Explain the CAP theorem and distributed consensus"
```
